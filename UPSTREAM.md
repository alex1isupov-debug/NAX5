# NAX5 upstream

NAX5 Client is based on chiaki-ng.

- Upstream: https://github.com/streetpea/chiaki-ng
- Baseline tag: `v1.10.0`
- Baseline branch: `nax5-baseline`
- Upstream engine version: chiaki-ng 1.10.0

NAX5 modifications are limited to product identity, settings isolation, Windows packaging, native NAX5 Backend authentication, console assignment, and transient Remote Play connect-info. Streaming core modifications: none.
