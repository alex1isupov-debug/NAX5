# NAX5 Alpha 0.2 upstream

NAX5 Alpha 0.2 is based on chiaki-ng.

- Upstream: https://github.com/streetpea/chiaki-ng
- Baseline tag: `v1.10.0`
- Baseline commit: `0c4a45df0cae2af2ba2daef84e881850b07038a3`
- NAX5 product version: Alpha 0.2
- Upstream engine version: chiaki-ng 1.10.0

NAX5 modifications are limited to:

- application and settings namespace isolation;
- application display branding;
- Windows product metadata;
- Windows portable packaging adjustments;
- native Cloud Console authentication (email + password) against django-allauth headless app APIs.

No NAX5 icon was supplied or found for this build, so the upstream icon is retained as a temporary placeholder. Branding icon pending.
