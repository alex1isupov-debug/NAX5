NAX5 Alpha 0.5 - Windows x64 installer

1. Run NAX5-windows-installer.exe and follow the setup wizard.
2. Launch NAX5 from the Start menu or desktop shortcut.
3. If you use the portable ZIP instead, extract it fully and launch chiaki.exe from that folder.
4. API base is https://cloudgta6.com - do not set NAX5_API_BASE_URL.
5. Do not set NAX5_OPERATOR_MODE.
6. SmartScreen warnings are expected for this unsigned alpha build.
7. PS5 should be in rest mode, not fully powered off.
8. Play requires verified email and ACTIVE access status on cloudgta6.com.
9. Logs: %AppData%/Roaming/NAX5/NAX5/log/
10. Save report button writes a ZIP to Desktop and uploads log tails when logged in.
11. Logout exits NAX5 account only; it does not power off the PS5.
